# Evidence-linked policy gap report

> This project does not assess UAE institutions. It tests whether a published-policy knowledge base enables accountable, evidence-grounded coordination during a hypothetical public-alert governance failure.

The scenario is hypothetical and fictional (`DISCLAIMER.md`). Findings are about what the published documents establish, not about any institution's conduct.

## 1. Scenario

- **E1** (t+0 min; visible to: Telecom/Operator role): Network monitoring shows a cell-broadcast message delivered to roughly 40,000 handsets in the fictional Northvale district. The operator's alert-request log has no matching request. The message heading reads 'Emergency warning' and contains no actionable instruction.
- **E2** (t+4 min; visible to: Emergency Management role): Public reports (unverified, from several social-media accounts) say residents of Northvale received an 'Emergency warning' on their phones. No official source has been identified. Some posts say people are calling relatives and a few are leaving work.
- **E3** (t+9 min; visible to: Telecom/Operator role): The operator's engineers confirm the message passed through the shared alert gateway interface and was broadcast by the operator's network. The gateway log shows no authenticated originator field for this message.
- **E4** (t+15 min; visible to: Emergency Management role, Policy Adviser role): A municipal operations room in Northvale asks whether the alert is genuine and whether residents should be told to act. A second municipal office asks the same. Neither received any instruction through official channels.
- **E5** (t+22 min; visible to: Telecom/Operator role): The gateway vendor's engineer reports a configuration fault on the gateway: a test-mode setting was left enabled, so a message intended only for an internal test profile was released to the live Northvale cell group. The vendor says it cannot itself cancel or correct a message already delivered.
- **E6** (t+30 min; visible to: Emergency Management role, Policy Adviser role): Journalists ask which body is responsible for telling the public the alert was sent in error and who will do it. Several residents ask on public channels whether it is safe to ignore the alert.
